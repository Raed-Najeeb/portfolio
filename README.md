# Raed Najeeb — Portfolio

React + Vite portfolio for AI/LLM systems projects.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Add the resume PDF

Place the final resume PDF at `public/resume.pdf`. The header and contact-section download links already point to `/resume.pdf` and use the browser's download behavior. The current resume PDF is included at `public/resume.pdf`. Replace that file whenever you update your resume.
