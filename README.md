# Raed Najeeb — Portfolio

A clean, responsive React + Vite portfolio featuring hands-on AI/ML projects, implementation details, and measured results. The projects reflect learning through building and testing rather than claims of production-scale systems.

## Featured projects

- **nanoGPT from scratch** — a character-level GPT implemented in PyTorch.
- **RAG pipeline** — local retrieval-augmented generation with retrieval checks and refusal behavior.
- **Emotion classification with LoRA** — a parameter-efficient adaptation compared with a full fine-tuning baseline.
- **EvalLab** — a deterministic evaluation pipeline with validated inputs, retrieval and abstention metrics, JSON reporting, and automated tests.
- **CareerMate** — an AI-assisted recruitment project.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
